# 틈 — 하루 한 틈, 영어 단어

한국어 사용자를 위한 모바일 반응형 영어 단어 암기 사이트. HTML/CSS/JavaScript만 사용하며 서버, 계정, 빌드 과정이 필요 없습니다.

## 단어 데이터

첨부된 `3000.xls`의 실제 단어 3,000개를 사용합니다. 초등 800개, 중고 1,800개, 전문 400개. 뜻과 수준은 원본 그대로 유지합니다. 원본은 `source/3000.xls`, 사이트 데이터는 `data/words.json`입니다.

원본 수정 후 데이터 생성 (Node.js 필요):

```sh
node scripts/convert.cjs
```

## 로컬 실행

저장소 폴더에서:

```sh
python3 -m http.server 8000
```

브라우저에서 해당 서버를 열면 됩니다. 파일을 직접 여는 방식은 JSON 로딩이 제한될 수 있으므로 HTTP 서버를 사용하세요. 하위 디렉터리에 배포해도 동작하도록 상대 경로와 해시 라우팅을 사용합니다.

## 기능

- 홈: 전체 단어, 최근 정답 단어, 복습 대상 현황
- 단어 암기: 수준 선택, 10/20/50/전체 단어, 무작위 순서, 뜻 확인 후 자가 평가
- 오답 노트: 현재 오답과 역대 오답을 분리. 재학습 정답은 현재 오답에서 제외하고 누적 오답 횟수 유지
- 전체 단어: 수준 필터, 영단어/한국어 뜻 검색, 페이지당 40개
- 영단어 발음: 브라우저 음성 합성 지원 시 사용 (기기의 음성 엔진/네트워크에 따라 다름)
- Excel 불러오기: 시트 및 단어/뜻/수준 열 선택, 중복 제거, 동일 단어/뜻/수준의 기존 기록 유지
- JSON 백업/복원: 단어와 학습 기록을 다른 기기로 옮길 수 있음
- 키보드: Enter 뜻 확인, ← 오답, → 정답. 화면 버튼으로도 모든 기능 사용 가능

학습 기록과 불러온 단어는 **이 브라우저의 localStorage**에만 저장합니다. 기기 간 자동 동기화가 없고, 시크릿 모드 종료나 브라우저 데이터 삭제로 기록이 사라질 수 있으므로 필요하면 백업하세요. 사용자 파일은 서버로 업로드하지 않습니다. 단어장 교체 전 백업을 권장합니다. 사용자별로 불러온 단어는 다른 사람에게 공유되지 않습니다. 공통 단어장을 바꾸려면 `data/words.json`을 업데이트해 배포하세요. 기존 사용자가 로컬에 단어장을 저장했다면 새 단어장을 불러오거나 백업 후 해당 사이트 저장 데이터를 삭제해야 공통 데이터 변경이 반영됩니다.

## GitHub Pages 배포

1. 이 파일들을 `ciderated/EnglishWord`의 `main` 브랜치에 커밋하고 push합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. Actions의 `Deploy static site to GitHub Pages` 실행이 완료되면 제공된 주소에서 이용합니다.

배포 workflow는 실제 사이트 파일만 업로드합니다. 이 작업에서는 원격 push나 실제 게시를 수행하지 않습니다.

## 브라우저 검증

Python HTTP 서버가 실행 중일 때 Playwright가 설치된 환경에서:

```sh
node tests/smoke.cjs
```

Playwright 설치가 필요하다면 `npm ci` 후 `npx playwright install chromium`을 실행합니다. 시스템 Chromium이 있으면 테스트가 `/usr/bin/chromium`을 사용합니다. 테스트는 독립 브라우저 컨텍스트에서 실행되며 학습·오답 재학습·역대 이력·리로드 지속성·원본 Excel 읽기·백업 복원·모바일 레이아웃을 확인합니다.
